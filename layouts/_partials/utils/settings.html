{{- /* utils/settings.html — the single place Runbook reads configuration. Returns one fully-resolved settings map, so no template ever has to remember a default or spell a key twice. Call it cached — the answer cannot vary per page: {{- $rb := partialCached "utils/settings.html" . -}} Two rules this file exists to enforce: 1. **Every key is namespaced under `params.runbook`** (contracts §2.4). Nothing is read from a bare top-level param, so Runbook can never collide with a consumer's own keys. 2. **`| default true` is a bug for any boolean whose default is true.** A consumer who writes `showLastmod = false` gets `false | default true` → `true`, and their setting is silently ignored. Booleans are therefore resolved with `isset`, which distinguishes "absent" from "present and false". `isset` is case-sensitive and Hugo lower-cases every param key, so the probes below are lower-case on purpose. Defaults here are the same values the repo-root `hugo.toml` ships, restated so the theme still behaves correctly when a consumer's config omits the block entirely — and so keys added after the root config was frozen have a home.
