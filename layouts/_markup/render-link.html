{{- /* render-link.html — specs/003 §3.5. External links get `rel="noopener noreferrer"` and a class the stylesheet turns into an indicator. `target="_blank"` is NOT the default: hijacking the back button is a usability decision that belongs to the site, not the theme, and this archive averages 4.39 internal links per post. Consumers who want it set `params.runbook.externalLinksNewTab = true`, and only then does the link also carry a visually-hidden "(opens in a new tab)" so the behaviour is announced rather than sprung — WCAG 3.2.5. The indicator itself is CSS (`.rb-link-external::after`), not an inline SVG. At the measured link density an SVG per external link is real page weight for something a pseudo-element does for free, and an `aria-hidden` icon adds nothing an assistive technology can use. "External" is decided by hostname, so a consumer whose baseURL is a subdirectory still gets its own absolute links treated as internal. A scheme-only destination (`mailto:`, `tel:`) has no hostname and is treated as external, which is correct — it leaves the site. */ -}} {{- $rb := partialCached "utils/settings.html" .Page -}} {{- $u := urls.Parse .Destination -}} {{- $external := false -}} {{- if $u.IsAbs -}} {{- $external = ne $u.Hostname (urls.Parse site.BaseURL).Hostname -}} {{- end -}} {{- $newTab := and $external $rb.externalLinksNewTab -}} {{ .Text }}{{ if $newTab }} {{ i18n "externalLinkNewTab" }}{{ end }}
